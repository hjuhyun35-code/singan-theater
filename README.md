# 책 봇 — 신간 요약을 쓰레드/인스타에 올리는 도구

알라딘에서 신간을 가져와 → Claude가 소개 문구를 쓰고 → 인스타용 카드 이미지를 만들어
→ **내가 승인한 것만** 쓰레드와 인스타그램에 올립니다.

## 처음이라면

1. **`설정안내.md`** 를 열어 1단계(알라딘 + Claude 키)만 먼저 하세요. 15분이면 됩니다.
2. `실행.bat` 을 더블클릭 → 초안이 어떻게 나오는지 확인하세요.
3. 결과물이 마음에 들면 그때 2단계(Meta 앱)로 넘어가세요.

## 파일 안내

| 파일 | 역할 |
|---|---|
| `실행.bat` | **평소 이것만 씁니다.** 초안 만들고 승인 화면 열기 |
| `승인화면만.bat` | 새로 만들지 않고 기존 초안만 다시 보기 |
| `설정확인.bat` | 키가 제대로 들어갔는지 점검 |
| `토큰갱신.bat` | 쓰레드/인스타 토큰 60일 연장 (두 달에 한 번) |
| `config.json` | **봇의 성격.** 분야, 하루 건수, 말투, 카드 구성 |
| `.env` | **비밀 키.** 절대 공유 금지 |
| `설정안내.md` | 키 발급 단계별 안내 |

## 동작 방식

```
알라딘 API          →  신간 목록 + 소개글 + 목차
   ↓
Claude (Haiku)      →  소개글을 베끼지 않고 다시 쓴 문구
   ↓
크롬 렌더링          →  1080×1350 카드 이미지 (JPEG)
   ↓
승인 화면 (내 컴퓨터) →  읽어보고, 고치고, 고른다   ← 여기서 멈춤
   ↓
imgbb → 쓰레드 API / 인스타 API
```

발행 버튼을 누르기 전까지 인터넷에는 아무것도 올라가지 않습니다.

## 비용

| 항목 | 월 비용 |
|---|---|
| 알라딘 API | 무료 (하루 5,000회) |
| Claude API | 1,000원 이하 (하루 3건 기준) |
| imgbb 이미지 호스팅 | 무료 |
| 쓰레드 / 인스타 API | 무료 |

## 한계 — 솔직히

- AI는 책을 읽지 않았습니다. 출판사 소개글과 목차를 근거로 쓴 **소개 문구**이지,
  읽고 쓴 서평이 아닙니다.
- 자료가 빈약한 책은 문구도 얕게 나옵니다. 승인 화면에 경고가 뜨면 건너뛰세요.
- `이야기` · `상황` 카드의 장면은 **봇이 만든 예시**이지 책에 실린 일화가 아닙니다.
  책 사례인 것처럼 쓰지 못하게 막아뒀지만, 승인 화면에서 한 번 읽어보세요.
- 자동화가 팔로워를 늘려주지는 않습니다. 계정이 자리 잡는 건 결국
  **어떤 분야를 좁게 파느냐**와 **직접 손댄 문장이 얼마나 되느냐**에 달려 있습니다.
